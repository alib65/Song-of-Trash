# Song of Trash (2024)

Song of Trash examines the sounds and aesthetic qualities of waste, turning discarded materials into creative inspiration. The piece invites listeners to hear trash not as useless leftovers but as active elements in an abstract soundscape.

The music is generated by the SuperCollider code in this repository, which synthesizes sounds that imitate the unpredictable noises of trash, such as rustling paper and clanging metal. The animated notation was designed in Photoshop.

- Video (premiered November 2024): https://www.youtube.com/watch?v=NDToNWrAB3o
- Presented at Laboratorio de Ecología Acústica en México (LEAM), Mexico City, 2025

## Run it
1. Open the .scd file in SuperCollider (3.13 or later).
2. Evaluate the whole file to boot the server and play the piece.
